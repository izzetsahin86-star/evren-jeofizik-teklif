# Evren Jeofizik Teklif

Evren Jeofizik için hazırlanmış teklif, müşteri ve hizmet kataloğu yönetim uygulaması.

## Özellikler

- Teklif panosu ve durum istatistikleri
- Teklif oluşturma, düzenleme, kopyalama ve silme
- Hizmet kataloğundan teklif kalemi ekleme
- Otomatik ara toplam, KDV ve genel toplam hesabı
- Gelişmiş teklif arama ve filtreleme
- Müşteri ve hizmet kataloğu yönetimi
- Birden fazla teklif veren firma ve varsayılan firma seçimi
- Yazdırılabilir / PDF olarak kaydedilebilir teklif görünümü
- Mobil ve masaüstü uyumlu arayüz

## Veri saklama

Bu ilk sürüm verileri cihazın tarayıcı depolamasında saklar. Veriler aynı tarayıcıda sayfa yenilendiğinde korunur. Çok kullanıcılı merkezi veri yönetimi gerektiğinde uygulama bir veritabanına bağlanabilir.

## Yerel çalıştırma

```bash
npm run dev
```

JavaScript sözdizimi kontrolü:

```bash
npm run check
```
